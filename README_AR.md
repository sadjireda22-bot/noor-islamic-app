# نُور — تطبيق إسلامي لأندرويد (مشروع تأسيسي)

## ماذا يحتوي؟
- واجهة عربية RTL بالأخضر الزمردي والذهبي.
- فهرس 114 سورة، وخياران لعرض الآيات: الرسم القرآني أو كتابة عربية مبسطة دون التشكيل وعلامات الوقف.
- بحث في نص القرآن كاملًا عند الاتصال، مع تجاهل التشكيل الشائع والانتقال مباشرةً إلى السورة والآية. يحفظ فهرس البحث على الجهاز عند توفر مساحة؛ وفي وضع عدم الاتصال يبحث في السور المحفوظة فقط.
- يجلب النص بالرسم العثماني من AlQuran Cloud ويحفظ السور المحمّلة محليًا.
- مواقيت الصلاة لوهران عبر AlAdhan (طريقة 3 كبداية).
- تاريخ هجري عبر تقويم أندرويد/المتصفح.
- صفحات أذكار ومناسبات توضيحية، ووضع فاتح/داكن.
- غلاف Android WebView مع ملفات HTML/CSS/JS المضمّنة.

## مهم قبل النشر
هذه **نسخة أولية قابلة للتشغيل والتطوير وليست إصدارًا شرعيًا نهائيًا**. نص القرآن يُجلب عبر الإنترنت من AlQuran Cloud ثم يُخزّن لكل سورة. لا تدّعِ أن جميع السور متوفرة دون اتصال قبل تنزيلها. راجع النصوص والأذكار والتواريخ ومواقيت الصلاة مع مصادر معتمدة في الجزائر. التواريخ الهجرية والأعياد قد تختلف برؤية الهلال. ميزة الصوت والتنبيهات الدقيقة ليست منفذة بعد.

## تشغيل الواجهة داخل Termux
1. ثبّت Termux من مصدر موثوق، ثم:
   ```sh
   pkg update && pkg upgrade
   pkg install python
   termux-setup-storage
   ```
2. فك ضغط المشروع إلى مجلد يمكن الوصول إليه، ثم انتقل إلى `web`:
   ```sh
   cd ~/storage/downloads/NOOR_Islamic_App/web
   python -m http.server 8080
   ```
3. افتح `http://127.0.0.1:8080` في المتصفح. ستحتاج الإنترنت لجلب القرآن أول مرة ومواقيت الصلاة. يمكن تثبيت الواجهة كتطبيق ويب من المتصفح إذا كان الخيار متاحًا.

## بناء APK
مجلد `android/` مشروع Android Gradle يستخدم Android Gradle Plugin 8.7.3 وSDK 35. أسهل طريق على الهاتف: افتح مجلد `android` في AndroidIDE، ثبّت SDK المطلوب، ثم نفّذ Gradle task `assembleDebug`. سيظهر APK في:
`android/app/build/outputs/apk/debug/app-debug.apk`

Termux وحده لا يحتوي افتراضيًا على Android SDK كامل. بناء APK مباشرة من Termux يتطلب إعداد Android SDK وGradle متوافقين، لذلك لا أزعم أن أمرًا واحدًا سيبنيه دون تجهيز. يمكن تشغيل نسخة الويب الآن، وبناء APK بعد إعداد بيئة أندرويد.
